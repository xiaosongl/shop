# 商品资料提交格式

这份和 `商品导入模板.csv` 一起发给供货方。对方照模板填好回传，我们在后台「商品 → 批量导入」一次传完。

## 怎么填

用 Excel 打开模板，**在示例行下面接着填，一个商品一行**，填完删掉那 4 行示例，另存为 **CSV UTF-8**（Excel 另存为对话框里选「CSV UTF-8（逗号分隔）」，不要选普通的「CSV（逗号分隔）」，后者存中文会乱码）。

描述里可以放逗号和引号，Excel 会自己处理，不用手动加转义。

**回传时发两样**：填好的 CSV，加上一个装着所有商品图的文件夹。图片不用传网盘换链接，见下面「图片」那节。

## 每一列

| 列名 | 必填 | 说明 |
| --- | --- | --- |
| `slug` | 否 | 商品网址后缀。留空我们按标题自动生成。填了的话以后改价改描述可以重传同一份表，系统认它是同一件商品 |
| `title` | **是** | 商品名，英文，前台直接显示 |
| `description` | **是** | 商品描述，英文，一段话 |
| `details` | 否 | 材质、尺寸、洗涤这类，**用竖线 `\|` 分行**，前台显示成列表 |
| `brand` | **是** | 品牌名。库里没有的会自动新建，所以同一个品牌前后写法要统一，别一会儿 `Northwell` 一会儿 `North Well` |
| `category` | **是** | 只能从下面那张表里选，填英文 slug 或中文名都行 |
| `gender` | 否 | `men` / `women` / `unisex`，留空当 `unisex`。包和表这类通常填 `unisex`，男女入口下都会出现 |
| `status` | 否 | `active` 上架 / `draft` 草稿，留空当 `active`。拿不准的填 `draft`，进后台确认后再上架 |
| `price` | **是** | **Premium** 售价，**按美元填**，如 `189.00`。带 `$` 和千分位逗号也认。Exclusive 前台自动加 $90–$150，不用另填一列 |
| `compare_at` | 否 | 划线原价，按美元填。填了前台会显示折扣 |
| `featured` | 否 | `yes` 进首页精选栏，留空或 `no` 不进 |
| `colors` | 否 | 逗号分隔。想让前台显示色块就写成 `名字:色号`，如 `Sand:#d9cfc0, Black:#141414`；不写色号也行 |
| `sizes` | 否 | 逗号分隔，如 `S,M,L,XL` 或 `40,41,42,43`。均码写 `OS` |
| `stock` | 否 | **每个规格各这么多件**。留空表示不改库存（重传时用得上） |
| `images` | 否 | **图片文件名**（推荐）或图片直链，多张**用竖线 `\|` 隔开**，第一张是主图。夹一条 `.mp4` / `.webm` 直链会当成详情页视频，不当图片，一件只留第一条 |

**规格是颜色 × 尺码的组合。** 填 2 个颜色 × 4 个尺码，系统会生成 8 个规格，每个规格的库存都是 `stock` 那一列的数。想给不同规格设不同库存，先导进来再到后台单独改。

## 图片：直接发文件就行

**推荐做法**：图片放在一个文件夹里，表格 `images` 那列写**文件名**，表格和文件夹一起打包发过来。

```
images 列填：  weekender-01.jpg|weekender-02.jpg
文件夹里放：   weekender-01.jpg  weekender-02.jpg
```

不用先把图传到网盘或图床再换成链接。我们导入时会把表格和这些图一起选中，系统自己对应。

- 文件名要和表格里写的**完全一致**（大小写不敏感，`.jpg` `.png` `.webp` 都行）。
- 文件名里别用竖线 `|`，那是分隔多张图用的。
- 一个商品最多 12 张，单张不超过 12MB。
- 图片本身如果已经有公网直链，也可以直接填链接（`https://` 开头），和文件名可以混着用。填链接的话必须是**能直接打开图片本身**的地址，网盘分享页、需要登录的相册都抓不下来。

**关于构图**：系统统一裁成 3:4 竖版，所以竖构图最好，横图会被裁掉两边。第一张是主图。

配图失败不影响商品导入 —— 商品照样建好，补齐图片后重传同一份表就会补上（已经有图的商品不会重复处理）。

## 几个容易出错的地方

- **价格是美元，不是分。** `189.00` 是一百八十九美元。写成 `18900` 会变成一万八千九百美元。
- **品牌名前后要一致**，写法不同会被当成两个不同品牌。
- **一行一个商品**，不要把同一件商品的不同颜色拆成多行——颜色写在 `colors` 那一列里。
- **别删表头**，第一行的列名要原样保留。
- 单价必须**高于 15 美元**（最低 `15.01`）。客户选「不带盒发货」会减 15 美元，正好 15 美元的商品会被算成 0 元订单。

回传前不用自己检查，我们后台传上去会先出预览：哪些是新建、哪些是更新、哪几行有问题，都列清楚了才写入。
